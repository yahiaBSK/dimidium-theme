# Dimidium Theme

A sleek, dark terminal-inspired theme designed for Visual Studio Code. Dimidium provides a clean, distraction-free environment for developers who love command-line aesthetics.

## Features

- **Terminal Aesthetic:** Dark high-contrast colors inspired by modern command-line interfaces.
- **Eye-Friendly Contrast:** Carefully selected syntax highlighting to reduce eye strain during long coding sessions.
- **Minimalist Design:** Keeps UI distraction to a minimum while maintaining clear visual hierarchy.

---

## Installation

1. Open **Visual Studio Code**.
2. Go to Extensions (`Ctrl+Shift+X` or `Cmd+Shift+X`).
3. Search for `Dimidium Theme`.
4. Click **Install**.
5. Click **Set Color Theme** (or press `Ctrl+K` `Ctrl+T` and select **Dimidium**).

---

## Activation

You can easily activate the theme at any time via settings:

1. Press `Ctrl+K` followed by `Ctrl+T` (or `Cmd+K` `Cmd+T` on macOS).
2. Select **Dimidium** from the drop-down menu.
